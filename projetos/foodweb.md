# Food Web — sistema para operações de alimentação

[Visitar o site](https://foodweb.site) · [Voltar ao perfil](../README.md)

## Proposta

Reunir tarefas de atendimento e gestão em uma aplicação web: vendas, pedidos, mesas, caixa, estoque e acompanhamento da operação.

## Escopo desenvolvido

O código reúne módulos de PDV, comandas, cardápio digital, estoque, relatórios, gestão de funcionários e ponto, além da administração da plataforma.

## Decisões técnicas

- Frontend em HTML, CSS e JavaScript, organizado em módulos de negócio.
- API Node.js/Express para autenticação, acesso aos dados e funções.
- PostgreSQL como banco relacional.
- Build de distribuição e hospedagem na Vercel.
- Testes de regras e integrações presentes no repositório privado.

## O que este projeto demonstra

Integração de interfaces com regras de negócio, organização de uma aplicação com múltiplos módulos e manutenção de um backend conectado a banco relacional.

## Acesso

O site publicado é um ambiente real. Áreas internas dependem de uma conta autorizada; não há credenciais de demonstração públicas. O código e a documentação operacional permanecem privados.
