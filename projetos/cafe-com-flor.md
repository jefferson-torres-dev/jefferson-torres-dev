# Floricultura Café com Flor — catálogo digital

[Visitar o site](https://floriculturacafecomflor.site) · [Voltar ao perfil](../README.md)

## Proposta

Apresentar os produtos da floricultura na web e oferecer uma interface para manter o catálogo atualizado.

## Escopo desenvolvido

- Catálogo público de produtos.
- Página para reunir links do negócio.
- Interface administrativa com autenticação.
- Cadastro e manutenção de produtos e imagens.

## Decisões técnicas

O frontend usa HTML, CSS e JavaScript, sem etapa de compilação. A integração com Supabase atende autenticação, catálogo e armazenamento de imagens. A publicação é feita na Vercel.

## O que este projeto demonstra

Construção de uma presença digital para um negócio, integração com serviços de dados e criação de uma interface administrativa para atualizar conteúdo.

## Acesso

O catálogo pode ser visitado pelo link acima. A administração é restrita a usuários autorizados. Código, configurações internas e dados administrativos não integram este estudo de caso. Marca e imagens pertencem aos respectivos titulares.
